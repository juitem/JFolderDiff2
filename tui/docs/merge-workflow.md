# 머지 워크플로우

## 개념

FolderDiff의 머지는 **청크(chunk) 단위**로 동작합니다. 각 diff 청크에 대해 독립적으로 "왼쪽 채택" 또는 "오른쪽 채택"을 결정하고, 저장 시 해당 결정을 일괄 적용합니다.

## 결정 방향

| 키 | 방향 | 의미 |
|---|---|---|
| `→` / `l` | 왼쪽 채택 (L→R) | 이 청크에서 **왼쪽 내용**을 채택 → **오른쪽 파일**에 반영 |
| `←` / `h` | 오른쪽 채택 (R→L) | 이 청크에서 **오른쪽 내용**을 채택 → **왼쪽 파일**에 반영 |

## 단계별 흐름

```
1. 폴더 화면에서 수정된 파일 선택 (Enter)

2. 파일 diff 화면 진입
   - 자동으로 첫 번째 diff 청크로 스크롤

3. n / p 로 청크 이동

4. 각 청크에서:
   - → : 왼쪽 채택 (오른쪽 파일을 왼쪽으로 덮어쓸 예정)
   - ← : 오른쪽 채택 (왼쪽 파일을 오른쪽으로 덮어쓸 예정)
   - u  : 이 청크 결정 취소

5. s / Ctrl+S 로 저장
   - LEFT 결정이 있으면 → 오른쪽 파일 저장
   - RIGHT 결정이 있으면 → 왼쪽 파일 저장
   - 저장 후 diff 자동 재계산

6. b / Esc 로 폴더 화면으로 복귀
```

## 색상 코드

| 색상 | 의미 |
|---|---|
| 빨강 (왼쪽) | 왼쪽에만 있는 줄 (`delete`) |
| 초록 (오른쪽) | 오른쪽에만 있는 줄 (`insert`) |
| 노랑 (왼쪽) / 청록 (오른쪽) | 양쪽이 다른 줄 (`replace`) |
| 더 밝은 배경 | 현재 커서가 위치한 청크 |
| 초록 (양쪽) + ✓ | LEFT 결정 완료 |
| 파랑 (양쪽) + ✓ | RIGHT 결정 완료 |

## 저장 동작 상세

`apply_to_right(chunks)`:
- 각 청크 순회
- `equal` → 오른쪽 원본 유지
- `LEFT 결정` → 왼쪽 내용으로 교체
- 결정 없음 → 오른쪽 원본 유지

`apply_to_left(chunks)`:
- 각 청크 순회
- `equal` → 왼쪽 원본 유지
- `RIGHT 결정` → 오른쪽 내용으로 교체
- 결정 없음 → 왼쪽 원본 유지

저장이 완료되면 diff를 재계산하여 현재 상태를 반영합니다.

## 주의사항

- 결정을 내리지 않은 청크는 **원본 파일 내용이 유지**됩니다.
- 저장 전에 `u`로 개별 청크 결정을 언제든 취소할 수 있습니다.
- `Ctrl+→` / `Ctrl+←`로 모든 청크를 일괄 채택할 수 있습니다.
