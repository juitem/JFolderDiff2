# FolderDiff

Meld 스타일의 폴더/파일 비교 및 머지 도구. 터미널에서 동작하는 TUI 앱입니다.

## 설치

```bash
pip install -r requirements.txt
```

## 실행

```bash
python main.py <왼쪽_경로> <오른쪽_경로>
```

예시:

```bash
python main.py ~/project-v1 ~/project-v2
```
