# 키보드 단축키

## 폴더 비교 화면

| 키 | 동작 |
|---|---|
| `↑` / `↓` | 항목 이동 |
| `Enter` | 파일 열기 / 폴더 펼치기·접기 |
| `Space` | 폴더 펼치기·접기 |
| `Tab` | 다음 diff 항목으로 점프 |
| `f` | diff 항목만 필터링 (토글) |
| `r` | 새로고침 |
| `q` | 종료 |

## 파일 diff / 머지 화면

### 탐색

| 키 | 동작 |
|---|---|
| `↑` / `↓` 또는 `k` / `j` | 스크롤 |
| `PageUp` / `PageDown` | 페이지 단위 스크롤 |
| `n` / `Tab` | 다음 diff 청크로 이동 |
| `p` / `Shift+Tab` | 이전 diff 청크로 이동 |

### 머지

| 키 | 동작 |
|---|---|
| `→` 또는 `l` | 현재 청크: 왼쪽 채택 → 오른쪽 파일에 반영 |
| `←` 또는 `h` | 현재 청크: 오른쪽 채택 → 왼쪽 파일에 반영 |
| `Ctrl+→` | 모든 청크 왼쪽 일괄 채택 |
| `Ctrl+←` | 모든 청크 오른쪽 일괄 채택 |
| `u` | 현재 청크 결정 취소 |

### 파일 조작

| 키 | 동작 |
|---|---|
| `s` 또는 `Ctrl+S` | 수정된 파일 저장 |
| `b` 또는 `Esc` | 폴더 화면으로 돌아가기 |
