# GUI 요구사항 명세

## 1. 개요

FolderDiff Web GUI는 브라우저에서 동작하는 폴더/파일 비교·머지 도구입니다.
TUI 버전의 핵심 로직을 FastAPI 백엔드로 서빙하고,
Vanilla JS + ES 모듈 기반 SPA(Single Page Application)로 시각화합니다.

---

## 2. 기능 요구사항

### 2.1 폴더 브라우저

| ID | 요구사항 |
|----|----------|
| FB-01 | 왼쪽·오른쪽 경로를 독립적으로 선택할 수 있어야 한다 |
| FB-02 | 경로 선택 시 모달 다이얼로그로 파일시스템 트리를 탐색할 수 있어야 한다 |
| FB-03 | 폴더를 클릭하면 해당 폴더로 진입하고, 상위로 이동하는 버튼이 있어야 한다 |
| FB-04 | 현재 경로를 수동 입력할 수 있어야 한다 |
| FB-05 | 홈 디렉터리(`~`) 및 루트(`/`) 빠른 접근 버튼을 제공해야 한다 |
| FB-06 | 파일시스템 탐색은 키보드(↑↓ Enter Esc)로도 가능해야 한다 |

### 2.2 폴더 비교

| ID | 요구사항 |
|----|----------|
| FC-01 | 두 경로를 선택 후 "비교" 버튼 클릭 또는 Enter로 비교를 시작해야 한다 |
| FC-02 | 비교 결과를 파일/폴더 트리 형태로 표시해야 한다 |
| FC-03 | 각 항목에 상태 표시: `=` 동일 / `~` 수정 / `←` 왼쪽만 / `→` 오른쪽만 |
| FC-04 | 폴더는 펼치기·접기가 가능해야 한다 |
| FC-05 | 상단에 통계(동일 N, 수정 N, 왼쪽만 N, 오른쪽만 N)를 표시해야 한다 |
| FC-06 | `diff 항목만 보기` 필터 토글을 제공해야 한다 |
| FC-07 | 비교 중 로딩 인디케이터를 표시해야 한다 |
| FC-08 | 키보드 `Tab`으로 다음 diff 항목으로 점프할 수 있어야 한다 |

### 2.3 파일 diff / 머지

| ID | 요구사항 |
|----|----------|
| FD-01 | 파일 클릭 시 사이드-바이-사이드(side-by-side) diff 뷰로 전환해야 한다 |
| FD-02 | 왼쪽·오른쪽 파일 내용을 나란히 표시하며 라인 번호를 보여야 한다 |
| FD-03 | diff 청크별로 색상을 구분해야 한다 (삭제=빨강, 추가=초록, 수정=노랑/청록) |
| FD-04 | 현재 포커스된 diff 청크를 강조 표시해야 한다 |
| FD-05 | 청크별로 `→` (왼쪽 채택) / `←` (오른쪽 채택) 버튼을 클릭으로 제공해야 한다 |
| FD-06 | 채택된 청크는 색상으로 결정 상태를 시각화해야 한다 |
| FD-07 | `전체 왼쪽 채택` / `전체 오른쪽 채택` 일괄 버튼을 제공해야 한다 |
| FD-08 | 저장 버튼 클릭 시 결정된 내용을 파일에 반영하고 성공/실패를 알려야 한다 |
| FD-09 | 저장 후 diff를 재계산하여 화면을 갱신해야 한다 |
| FD-10 | 바이너리 파일의 경우 "바이너리 파일" 안내 메시지를 표시해야 한다 |

### 2.4 키보드 단축키 (파일 diff 화면)

| 키 | 동작 |
|----|------|
| `n` / `j` | 다음 diff 청크 |
| `p` / `k` | 이전 diff 청크 |
| `→` | 현재 청크 왼쪽 채택 |
| `←` | 현재 청크 오른쪽 채택 |
| `u` | 현재 청크 결정 취소 |
| `Ctrl+S` | 저장 |
| `Esc` | 폴더 비교 화면으로 복귀 |

### 2.5 UX / 비기능 요구사항

| ID | 요구사항 |
|----|----------|
| UX-01 | Catppuccin Mocha 다크 테마 기본 적용 |
| UX-02 | 알림(Notification)은 화면 우상단 토스트로 표시, 3초 후 자동 사라짐 |
| UX-03 | 긴 경로는 말줄임표로 처리하고 hover 시 전체 경로를 tooltip으로 표시 |
| UX-04 | 모든 API 오류를 사용자 친화적 메시지로 표시해야 한다 |
| UX-05 | 브라우저 뒤로가기 버튼이 뷰 전환에 동작해야 한다 (History API) |
| UX-06 | 페이지 새로고침 시 마지막 선택 경로를 localStorage에서 복원해야 한다 |

## 3. 비기능 요구사항

| 항목 | 기준 |
|------|------|
| 성능 | 1만 줄 이하 파일의 diff는 1초 이내 응답 |
| 보안 | 경로 탐색은 서버 파일시스템에 한정, 경로 트래버설 공격 방어 |
| 호환성 | 최신 Chrome / Firefox / Safari 지원 |
| 유지보수 | 빌드 도구 없는 Vanilla JS, 외부 JS 라이브러리 의존성 없음 |
| 확장성 | 컴포넌트 단위 분리로 독립 교체 가능 |
